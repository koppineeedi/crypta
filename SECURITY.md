# Security Policy & Cryptographic Specifications — Crypta

## Cryptographic Specifications

### 1. File Encryption Engine
- **Cipher Algorithm**: AES-256-GCM (Advanced Encryption Standard in Galois/Counter Mode with 256-bit key).
- **Authentication Tag**: 128-bit tag verified automatically by Web Crypto `subtle.decrypt()`.
- **Initialization Vector (IV)**: 12-byte (96-bit) cryptographically secure random IV generated per file (`crypto.getRandomValues()`).
- **Salt**: 16-byte (128-bit) cryptographically secure random salt generated per file (`crypto.getRandomValues()`).
- **Key Derivation Function (KDF)**: PBKDF2 (Password-Based Key Derivation Function 2) using HMAC-SHA-256.
- **KDF Iteration Count**: 100,000 iterations (centralized in `SECURITY_CONFIG`).

### 2. Binary File Packet Specification (Format V1)
Encrypted `.enc` files generated by Crypta follow a deterministic binary structure:

```text
+-----------------------+------------------------+-------------------+-----------------+----------------+--------------------+
| Magic Header (6B)     | Filename Length (2B)   | Filename (UTF-8)  | Salt (16B)      | IV (12B)       | Ciphertext + Tag   |
| "CRYPTA"              | Big-Endian Uint16      | Dynamic length    | PBKDF2 Salt     | AES-GCM IV     | Encrypted Payload  |
+-----------------------+------------------------+-------------------+-----------------+----------------+--------------------+
```

## Privacy & Network Disclosures

1. **Local Execution**: Crypta operates 100% inside the client browser. No backend server or cloud infrastructure receives your plaintext files or passwords.
2. **Breach Checking**: The password breach checker uses k-anonymity. The browser calculates the SHA-1 hash locally, truncates it to the first 5 hex characters, and queries the public Have I Been Pwned API over HTTPS (`https://api.pwnedpasswords.com/range/{prefix}`). If network access is blocked or fails, Crypta clearly states "Breach check unavailable" rather than false safety assurance.

## Reporting Vulnerabilities

If you discover a security vulnerability or cryptographic flaw within Crypta:
- **Do not open a public GitHub issue.**
- Please email details directly to the author: `koppineedi.vamsi@example.com` (or create a private vulnerability disclosure on GitHub).
- Include steps to reproduce, browser details, and proof-of-concept.
