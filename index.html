          Crypta Security Architecture

          • Local Browser Execution: Cryptography runs inside Web Crypto API.
          • Authenticated Encryption: Uses AES-GCM (256-bit) to prevent tampering.
          • Hardened Key Derivation: PBKDF2 with SHA-256 and 100,000 iterations.
          • Cryptographically Secure Randomness: Random salt & IV generated via crypto.getRandomValues().
          • Privacy-Preserving Breach Lookups: Transmits only 5 hex characters of SHA-1 hash via k-anonymity.

          Cybersecurity Knowledge Base

          What does password strength mean?
          Password strength measures a password's resistance to automated guessing attacks. It is primarily driven by password length, entropy (randomness), and the absence of predictable patterns.
          What is a dictionary attack?
          A dictionary attack uses automated software to test millions of common words, names, dictionary combinations, and leet-speak substitutions against password hashes.
          What is an offline attack?
          An offline attack occurs when an attacker obtains a database of hashed passwords and uses dedicated multi-GPU hardware to compute trillions of guesses per second without network throttling.
          Why is password reuse dangerous?
          If an attacker breaches one service where you reused a password, they will attempt automated "credential stuffing" attacks against hundreds of other websites using the same email and password combination.
          What is k-Anonymity breach checking?
          k-Anonymity ensures privacy by hashing your password with SHA-1 locally, and sending only the first 5 characters of the hash to the Have I Been Pwned server. The server responds with thousands of hash suffixes sharing those 5 prefix characters, allowing your browser to match the remaining characters locally without disclosing your password.
